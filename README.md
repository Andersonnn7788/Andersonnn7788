## How I engineer

I use AI as part of a disciplined engineering system rather than as a replacement for engineering judgment.

- Define architecture, repository conventions, and boundaries before implementation
- Give coding agents scoped context and tools through project instructions, skills, and subagents
- Use hooks, permissions, tests, linting, and builds as deterministic guardrails
- Treat security, privacy, consent, and observability as product requirements
- Validate AI behavior with evaluation datasets, measurable failure cases, and fallback paths
- Document important system decisions so that the codebase remains understandable as it grows
